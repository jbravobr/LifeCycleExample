# Ciclo de vida em Xamarin.Forms

> Aplicativo didático da primeira aula de desenvolvimento mobile do MIT Infnet, voltado ao ciclo de vida de uma aplicação Xamarin.Forms.

## Organização

- `Droid/` — projeto da plataforma Android.
- `LifeCycleExample/` — projeto ou módulo `LifeCycleExample`.
- `iOS/` — projeto da plataforma iOS.

## Tecnologias

C#, Xamarin.Forms e projetos para Android e iOS.
